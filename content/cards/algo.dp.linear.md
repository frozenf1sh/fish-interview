> **先识别方向**：题目沿数组、字符串或时间轴单向推进；每一步的答案只依赖已经完成的前缀状态。

## 用爬楼梯推导状态

走到第 `i` 级台阶，最后一步只有两种来源：从 `i-1` 走 1 级，或从 `i-2` 走 2 级。因此 `dp[i]` 定义为“到达第 i 级的方案数”，转移自然得到 `dp[i] = dp[i-1] + dp[i-2]`。

动画展示 `dp[0]` 到 `dp[5]` 的填写顺序。先看每个格子依赖谁，再看代码循环方向。

## Go 实现

```go
dp := make([]int, n+1)  // dp[i]：到达第 i 级的方案数
dp[0], dp[1] = 1, 1    // 空路径和走一级各算一种
for i := 2; i <= n; i++ {
	dp[i] = dp[i-1] + dp[i-2] // 最后一步来自 i-1 或 i-2
}
return dp[n] // 目标状态就是答案
```

> **状态检查**：写转移前先用一句完整的话读出 `dp[i]`；如果读不通，状态定义通常还不准确。

## 常见分叉

- `dp[i]` 表示“前 i 个元素的最优答案”时，答案通常在 `dp[n]`。
- `dp[i]` 表示“必须以 i 结尾”时，答案常是所有 `dp[i]` 的最大值。
- 空间压缩前，先确认当前状态只读取前面固定数量的状态。
